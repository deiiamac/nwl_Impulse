# NWL Impulse

Um widget de feedback interativo construído com React e Tailwind.

## 🎯 Sobre

Este projeto é um componente de widget flutuante que permite capturar feedback dos usuários através de uma interface elegante e responsiva.

## 🚀 Tecnologias

- **React** 18 - Biblioteca JavaScript para UI
- **Vite** - Build tool rápido e moderno
- **TypeScript** - Tipagem segura para JavaScript
- **Tailwind CSS** - Framework CSS utility-first
- **Phosphor React** - Ícones de alta qualidade

## 📦 Instalação

```bash
# Instalar dependências
npm install
```

## 🏃 Como Usar

```bash
# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview da build
npm run preview
```

## 📁 Estrutura do Projeto

```
src/
├── App.tsx           # Componente principal
├── main.tsx          # Ponto de entrada
├── global.css        # Estilos globais
└── components/
    └── Widget.tsx    # Widget de feedback
```

## ✨ Funcionalidades

- Widget flutuante no canto inferior direito
- Interface limpa e intuitiva
- Totalmente responsivo
- Animações suaves
